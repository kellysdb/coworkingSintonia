# Coworking Sintonia

Site institucional desenvolvido para o **Coworking Sintonia**, em Caraguatatuba - SP.

## Tecnologias

* HTML5
* CSS3
* JavaScript

## Funcionalidades

* Design responsivo
* Carrossel de imagens
* Galeria de espaços
* Modal de imagens
* Menu mobile
* Navegação suave

## Projeto

Site desenvolvido para apresentar os espaços, serviços e informações do Coworking Sintonia.
